# Oleksandr Nekrashevych — Portfolio Website

This is my personal engineering portfolio website showcasing projects in robotics, embedded systems, computer vision, and autonomous systems. The site is designed as an interactive experience with a custom animated background, project previews, and expandable project case studies.

---

## Live Website

https://nekrashevycholeksandr.github.io/Portfolio_Website/

---

## Features

- Interactive animated starfield background (HTML Canvas)
- Cyberpunk-style UI design with glow/grid effects
- Project cards with:
  - Image previews
  - Hover-to-play video previews
  - Click-to-expand modal views
- Detailed project breakdown sections
- Embedded demo videos
- Resume download link
- Fully responsive layout (desktop and mobile)
- Smooth intro transition animation

---

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla)

### Graphics and Interaction
- HTML5 Canvas API
- Custom particle system
- Real-time animation engine
- DOM-based modal system

## Running Locally

Clone the repository:

```bash
git clone https://github.com/NekrashevychOleksandr/Portfolio_Website.git
```

Navigate into the project folder:

```bash
cd Portfolio_Website
```

Run a local server:

```bash
python3 -m http.server 8000
```

Open in your browser:

http://localhost:8000
