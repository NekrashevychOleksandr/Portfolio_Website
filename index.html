Conversational Workflow Agent for Customer Service (WhatsApp System)

This system is a Node.js-based conversational automation agent designed to operate within WhatsApp, handling customer messages, routing requests, and managing escalation flows in real time. It is built as a workflow orchestration system rather than a traditional chatbot.

The agent processes incoming messages, classifies intent, and routes interactions into three primary flows: automated support responses, human handoff requests, and internal project request generation. Project-related messages are structured into formatted email summaries and sent to a team lead for review.

  • Intent classification and message routing logic (Node.js backend)
  • Automated customer support response system
  • Human escalation and live operator handoff flow
  • Project request detection with structured email generation
  • Priority and urgency tagging for internal workflows
  • WhatsApp integration via messaging API layer

The system demonstrates backend workflow design, conversational routing logic, and real-world automation of customer communication pipelines.

Vision-Based Autonomous Chess Agent (Real-Time System)

This project is a fully autonomous chess-playing agent that operates directly on live chess.com gameplay using computer vision and screen automation. It perceives the game state visually, computes moves, and executes them in real time.

The system is built around a closed perception–decision–action loop, where screen capture is interpreted into a structured board state, a move is generated, and then physically executed via mouse automation.

  • OpenCV-based chessboard detection and state extraction
  • Real-time screen parsing and piece recognition pipeline
  • Move decision system (engine-based or rule-driven logic)
  • PyAutoGUI-based mouse automation for move execution
  • Robust coordinate mapping between UI and internal board representation
  • Fully closed-loop autonomous gameplay on live web interface

The system demonstrates real-time autonomy in a dynamic UI environment, combining perception, reasoning, and action into a single operational loop.
