  • OS-level input automation enabling end-to-end autonomous gameplay loop

Autonomous Multi-Colour Line-Following Robot

Designed and implemented an autonomous embedded robotics system for the TUKS Robot Race Day competition, achieving a semi-finalist placement through robust real-time navigation and adaptive line tracking.

The system was developed entirely from first principles with no external libraries, including custom photodiode-based sensing circuitry, signal interpretation, and low-level assembly firmware for deterministic motor control and sensor processing.

  • First-principles photodiode-based line detection and analog signal processing (no external libraries)
  • Assembly-level embedded firmware on PIC microcontroller for real-time control
  • Multi-colour track selection and adaptive navigation logic (red, green, blue, black)
  • Closed-loop motor control with low-latency response system
  • Competition-validated autonomous navigation system (semi-finalist, TUKS Robot Race Day)
